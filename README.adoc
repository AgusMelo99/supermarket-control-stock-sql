== Introducción

El propósito de este trabajo práctico se basa en el desarrollo de un sistema digital, destinado al supermercado ChangoOnline, el cual sea capaz de administrar el ingreso, la cancelación, y la entrega de pedidos.
Además, se busca conservar toda la información de les clientes registrados y de los productos disponibles. Por último, se deberá controlar el stock de los productos y mantener a les clientes informados frente al estado de sus pedidos online.

== Descripción

La elaboración del trabajo, al comienzo, se habia complejizado en cuanto a cómo ibamos a abordar la estructura y el diseño tanto del código como de los archivos. Sin embargo, logramos definir un esquema para el cual se encuentre, por un lado, la aplicación CLI en lenguaje Go y, por otro, el contenido SQL encargado de realizar las consultas necesarias.
Cabe mencionar que, el CLI contiene un *package main* encargado de abrir una única conexión con la base de datos con la finalidad de que se lleven a cabo todas las operaciones establecidas y, además, muestra por consola opciones que permiten ejecutar el código en un orden específico conjunto la visualización del resultado. De esta manera, se encuentran distintos archivos .go que se ocupan de:
	* Crear la base de datos.
	* Crear tablas.
	* Crear las primary key y foreign key según corresponda.
	* Lectura de los datos .json (decoding) e insertar los registros en las tablas.
