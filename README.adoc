== Introducción

En este trabajo se busca desarrollar un sistema digital capaz de administrar el ingreso, la cancelación, y la entrega de pedidos, mantener
toda la información de les clientes y de los productos, y controlar que el stock disponible y el reservado de los productos sea actualizado 
correctamente. Les clientes deben ser informados vía email cuando ocurran eventos importantes sobre sus pedidos. Además, es necesario poder generar 
solicitudes de reposición para aquellos productos que hayan quedado con bajo stock.
