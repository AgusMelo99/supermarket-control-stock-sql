1. Introducción

El propósito de este trabajo práctico se basa en el desarrollo de un sistema digital, destinado al supermercado ChangoOnline, el cual sea capaz de administrar el ingreso, la cancelación, y la entrega de pedidos. Además, se busca conservar toda la información de les clientes registrados y de los productos disponibles. Por último, se deberá controlar el stock de los productos y mantener a les clientes informados frente al estado de sus pedidos online.

3.1. SQL

Creación del pedido

El archivo SQL se encarga de crear el stored procedure creacion_del_pedido(int, int), el cual toma como parámetro dos enteros, uno referenciado al id del cliente y otro para la id de la dirección. Este devuelve false si se rechaza la creación del pedido, insertando en la tabla error una fila con la información correspondiente del mismo, y true si se concreta. A continuación, se explicarán las condiciones a cumplirse para cada caso.

Para que dé falso

  • Si el id del usuario no existe, carga el error ?id de usuarie no válido.

  • Si la id de la dirección de entrega no existe para el cliente, carga el error ?id de dirección no válido.

  • Si el código postal vinculado a la dirección de entrega no tiene una tarifa establecida, carga el error ?dirección de entrega fuera del área de atención.

Para que dé true

  • Ninguna de las condiciones nombradas anteriormente tiene que cumplirse.

En caso de que se ejecute con éxito, se insertará una fila en la tabla pedido con los datos del cliente, la fecha, la hora del pedido y el costo de envío correspondiente al código postal, dejando su estado como ingresado.

-- \i archivo_de_prueba.sql

create or replace function creacion_del_pedido (id_cliente int, id_direccion int) returns boolean as $$

declare

    tarifa int;
    cp_corto char(4);
    id_del_pedidiho int;
    
begin
    -- verificar si existe el usuario
    if not exists (select 1 from cliente where id_usuarie = id_cliente) then
        --coalesce hace que si la tabla error este vacia devuelva como valor predeterminado 
        --el numero que se pone al final de la sentencia, en este caso 0
        insert into error(id_error, id_usuarie, f_error, motivo)
            values (coalesce((select max(id_error) from error), 0) + 1, id_cliente, current_date, '?id de usuarie no valido'); 
        return false;
    end if;
    
    -- verificar si la direccion de entrega existe
    if not exists (select 1 from direccion_entrega where id_direccion_entrega = id_direccion and id_usuarie = id_cliente) then
        --coalesce hace que si la tabla error este vacia devuelva como valor predeterminado 
        --el numero que se pone al final de la sentencia, en este caso 0
        insert into error(id_error, id_direccion_entrega, f_error, motivo)
            values (coalesce((select max(id_error) from error), 0) + 1, id_direccion, current_date, '?id de direccion no valido'); 
        return false;
    end if;
    
    -- obtener el codigo postal corto
    select substring(codigo_postal, 2, 4) into cp_corto from direccion_entrega where id_direccion_entrega = id_direccion and id_usuarie = id_cliente;
    
    -- verificar si el cp_corto tiene tarifa
    select costo into tarifa from tarifa_entrega where codigo_postal_corto = cp_corto;
    
    -- verificar si la tarifa es valida
    if tarifa is null then
        --coalesce hace que si la tabla error este vacia devuelva como valor predeterminado 
        --el numero que se pone al final de la sentencia, en este caso 0
        insert into error(id_error, id_direccion_entrega, f_error, motivo)
            values (coalesce((select max(id_error) from error), 0) + 1, id_direccion, current_date, '?direccion de entrega fuera del area de atencion'); 
        --raise 'direccion de entrega fuera del area de atencion';
        return false;
    end if;
    
    -- insertar pedido si todos los datos son correctos
    insert into pedido (id_pedido, f_pedido, id_usuarie, id_direccion_entrega, costo_envio, estado) 
        values (coalesce((select max(id_pedido) from pedido), 0) + 1, current_timestamp, id_cliente, id_direccion, tarifa, 'ingresado');
        
    select max(id_pedido) into id_del_pedidiho from pedido; 
    raise notice 'el id del pedido es: %', id_del_pedidiho;
    return true;
end;

$$ language plpgsql;
Agregado de producto

El archivo SQL se encarga de crear el stored procedure agregado_de_producto(int, int, cantidad), el cual toma como parámetro tres enteros, el primero referencia el id del pedido, el segundo el id del producto, y el tercero la cantidad del producto añadido que se agregará al producto. Se encarga de agregar al pedido con el id pasado como parámetro el producto con el id pasado como parámetro la cantidad de veces especificada previamente. Retorna un booleano el cual a continuación se explicarán las condiciones a cumplir para que el valor del mismo sea true o false.

Para que dé false

  • Si el id del pedido no existe, cargando el error con el mensaje ?id de pedido no válido.

  • Si el pedido no se encuentra en estado 'ingresado', cargando el error con el mensaje ?pedido cerrado.

  • Si el id de producto no existe, cargando el error ?id de producto no válido.

  • Que el producto tenga stock disponible para satisfacer la cantidad solicitada, cargando el error ?stock no disponible para el producto [id_producto].

Para que dé true

  • Todos los condicionales previamente nombrados no deben cumplirse.

En caso de que se ejecute con éxito, se insertará una fila en la tabla pedido_detalle con los datos del producto. Si el pedido ya tiene el producto, se deberá actualizar la fila correspondiente, sumando la nueva cantidad. En cualquiera de los dos casos, se descuenta dicha cantidad del stock disponible y se suma al stock reservado. También se mantiene actualizado el monto total del pedido de forma coherente con el detalle de productos listados.

create or replace function agregado_de_producto (pedido_id int, producto_id int, cantidad_producto int) returns boolean as $$

declare
    
    estado_pedido char(10);
    stock_producto int;
    precio_unitario_producto decimal(12,2);

begin
    RAISE NOTICE 'El nivel de aislamiento actual es: %', current_setting('transaction_isolation', true);
    -- verificar si existe el pedido
    if not exists (select 1 from pedido p where p.id_pedido = pedido_id) then
        insert into error(id_error, id_pedido, f_error, motivo)
            values (coalesce((select max(id_error) from error), 0) + 1, pedido_id, current_date, '?id de pedido no valido'); 
        
        return false;
    end if;

    -- verificar que el pedido se encuentre en estado 'ingresado'
    select estado into estado_pedido from pedido p where p.id_pedido = pedido_id;
    
    if estado_pedido != 'ingresado' then
        insert into error(id_error, id_pedido, f_error, motivo)
            values (coalesce((select max(id_error) from error), 0) + 1, pedido_id, current_date, '?pedido cerrado'); 
        
        return false;
    end if;
    
    -- verificar que el producto exista
    if not exists (select 1 from producto p where p.id_producto = producto_id) then
        insert into error(id_error, id_pedido, f_error, motivo)
            values (coalesce((select max(id_error) from error), 0) + 1, pedido_id, current_date, '?id de producto no valido'); 
        
        return false;
    end if;

    -- verificar si hay stock del producto
    select stock_disponible into stock_producto from producto p where p.id_producto = producto_id;
        
    if cantidad_producto > stock_producto then
        insert into error(id_error, id_pedido, f_error, motivo)
            values (coalesce((select max(id_error) from error), 0) + 1, pedido_id, current_date, '?stock no disponible para el producto' || ' ' || producto_id);  
        
        return false;
    end if;
        
    -- si llego hasta aca es porque se puede agregar el producto
        
    -- obtener el precio unitario del producto
    select precio_unitario into precio_unitario_producto from producto p where p.id_producto = producto_id;
    
    -- paso 1: descontar el stock disponible y agregarlo al stock reservado
    update producto set stock_disponible = (stock_disponible - cantidad_producto),
        stock_reservado = (stock_reservado + cantidad_producto) where id_producto = producto_id;
        
        
    -- paso 2: actualizar el monto total del pedido
    update pedido set monto_total = (coalesce(monto_total, 0) + (precio_unitario_producto * cantidad_producto)) where id_pedido = pedido_id;
    -- verificar si el producto ya esta en el pedido
    if not exists (select 1 from pedido_detalle p where p.id_producto = producto_id) then 
        -- paso 3: insertar el producto en pedido_detalle si no existe
        insert into pedido_detalle values (pedido_id, producto_id, cantidad_producto, precio_unitario_producto);
    else
        -- si existe, actualizar la cantidad
        update pedido_detalle set cantidad = (cantidad + cantidad_producto) where id_pedido = pedido_id and id_producto = producto_id;
    end if;
    return true;
end;

$$ language plpgsql;
Cierre del pedido

El archivo SQL se encarga de crear el stored procedure cierre_del_pedido(int, timestamp), el cual retorna un booleano el cual será true si se carga el pedido con éxito y false en caso contrario. Toma como parámetro el id del pedido y la fecha y hora de entrega. A continuación, se explicarán las condiciones a cumplir para que el valor de retorno sea true o false.

Para que dé false

  • Que el pedido con el id pasado como parámetro no exista, se cargará el error ?id de pedido no válido.

  • Que el pedido no tenga al menos un producto agregado, se cargará el error ?pedido vacío.

  • Que la fecha y hora de entrega no sea posterior a la actual, se cargará el error ?fecha de entrega no válida.

Para que dé true

  • Todos los condicionales anteriormente mencionados no deben cumplirse.

En caso de éxito, se actualizará la fila correspondiente en la tabla pedido con la fecha de entrega, y las horas de entrega desde y hasta, dejando su estado como completado.

create or replace function cierre_del_pedido (pedido_id int, fecha_y_hora_entrega timestamp) returns boolean as $$

declare
    cantidad_productos int;
    hora_entrega time;
    fecha_de_entrega date;
begin

    -- valida que el id del pedido exista en la tabla.
    if not exists (select 1 from pedido p where p.id_pedido = pedido_id) then
        -- se carga en la tabla el error
        insert into error(id_error, id_pedido, f_error, motivo)
        values (coalesce((select max(id_error) from error), 0) + 1, pedido_id, current_date, '?id de pedido no valido.'); 
        
        return false;
    end if;
    
    -- valida que el pedido tenga al menos un producto agregado.
    select cantidad into cantidad_productos from pedido_detalle pd where pd.id_pedido = pedido_id;
    
    if cantidad_productos < 1 then
    insert into error(id_error, id_pedido, f_error, motivo)
            values (coalesce((select max(id_error) from error), 0) + 1, pedido_id, current_date, '?pedido vacio'); 
        return false;
    end if;
    
    -- valida que la fecha de entrega del pedido sea mayor a la fecha actual.
    if fecha_y_hora_entrega < current_timestamp then 
    insert into error(id_error, id_pedido, f_error, motivo)
            values (coalesce((select max(id_error) from error), 0) + 1, pedido_id, current_date, '?fecha de entrega no válida'); 
        return false;
    end if;
    
    -- despues de validar todo:
    --actualiza la fecha de entrega
    --casteo la fecha de entrega a time para poder actualizar la tabla
    
    select cast(fecha_y_hora_entrega as date) into fecha_de_entrega;
    
    update pedido set fecha_entrega = fecha_de_entrega where id_pedido = pedido_id;
    
    -- actualiza la fecha de entrega del pedido desde y hasta que hora puede llegar.
    -- casteo la fecha de entrega a time para sacar la hora
    
    select cast(fecha_y_hora_entrega as time) into hora_entrega;

    update pedido set hora_entrega_desde = hora_entrega where id_pedido = pedido_id;
    update pedido set hora_entrega_hasta = (hora_entrega + interval '2 hour') where id_pedido = pedido_id;  
    
    --actualiza el estado del pedido
    update pedido set estado = 'completado' where id_pedido = pedido_id;    
    
    return true;

end;

$$ language plpgsql;
Cancelacion de pedido

El archivo SQL se encarga de crear el stored procedure cancelacion_de_pedido(int), el cual retorna un booleano que será true si se cancela el pedido con éxito y false en caso contrario. Este toma como parámetro el id del pedido. A continuación, se explicarán las condiciones a cumplir para que el valor de retorno sea true o false.

Para que dé false

  • El pedido con el id pasado como parámetro no existe, cargará el error ?id de pedido no válido.

  • Que el pedido no se encuentre en estado 'ingresado' o 'completado', cargará el error ?pedido ya entregado o cancelado.

En caso de que se ejecute con éxito, se marcará el estado del pedido como cancelado. Además, se deberá sumar al stock disponible de cada producto la cantidad incluida en el pedido cancelado, y descontarla del stock reservado.

create or replace function cancelacion_de_pedido (pedido_id int) returns boolean as $$ 

declare
    
    registro record;
    
begin
    -- valida que el id del pedido exista en la tabla.
    if not exists (select 1 from pedido p where p.id_pedido = pedido_id) then
        -- se carga en la tabla el error
        insert into error(id_error, id_pedido, f_error, motivo)
        values (coalesce((select max(id_error) from error), 0) + 1, pedido_id, current_date, '?id de pedido no valido.'); 
        
        return false;
    end if;
    
    --valida que el estado del pedido no sea ingresado o completado
    if not exists (select 1 from pedido p where p.id_pedido = pedido_id and p.estado = 'ingresado' or p.estado = 'completado') then
        -- se carga en la tabla el error
        insert into error(id_error, id_pedido, f_error, motivo)
        values (coalesce((select max(id_error) from error), 0) + 1, pedido_id, current_date, '?pedido ya entregado o completado.'); 
        
        return false;
    end if;
    
    --terminan validacion
    
    --cambia el estado del pedido a cancelado
    update pedido set estado = 'cancelado' where id_pedido = pedido_id; 
    
    --inicializo la transaccion
    -- por cada fila que esté relacionada con el id_pedido que fue cancelado, se guarda el id_producto y cantidad en la variable registro(record).
    for registro in select id_producto, cantidad from pedido_detalle where id_pedido = pedido_id loop
    
    -- actualiza la tabla producto restando al stock_reservado la cantidad del pedido cancelado.
        update producto set stock_reservado = (stock_reservado - registro.cantidad) where id_producto = registro.id_producto;
    -- actualiza la tabla producto sumando al stock disponible la cantidad del pedido cancelado
        update producto set stock_disponible = (stock_disponible + registro.cantidad) where id_producto = registro.id_producto;
    end loop;
    return true;
end;

$$ language plpgsql;
Entrega de pedido

El archivo SQL se encarga de crear el stored procedure entrega_pedido(int), el cual retorna un booleano que será true si se marca el pedido como entregado o false en caso contrario. Toma como parámetro un id referenciando el id del pedido. A continuación, se explicarán las condiciones a cumplir para que el valor de retorno sea true o false.

Para que dé false

  • El pedido con el id pasado como parámetro no existe, cargará el error ?id de pedido no válido.

  • Que el estado del pedido no se encuentre en 'completado', cargará el error ?pedido sin cerrar o ya entregado.

Para que dé true

  • Ninguna de las condiciones anteriores se cumplan.

Si se ejecuta con éxito, se marcará el estado del pedido como entregado. Además, se restará el stock reservado de cada producto la cantidad incluida en el pedido entregado.

create or replace function entrega_pedido(pedido_id int) returns boolean as $$

declare

    estado_pedido pedido.estado%type;
    registro record;
    
begin
    --valida que haya un pedido_detalle con el id del pedido
    if not exists (select 1 from pedido_detalle p where p.id_pedido = pedido_id) then
        insert into error(id_error, id_pedido, f_error, motivo)
        values (coalesce((select max(id_error) from error), 0) + 1, pedido_id, current_date, '?no hay detalle de este pedido.'); 
        return false;
    end if;
    
    -- valida que el id del pedido exista en la tabla.
    if not exists (select 1 from pedido p where p.id_pedido = pedido_id) then
        -- se carga en la tabla el error
        insert into error(id_error, id_pedido, f_error, motivo)
        values (coalesce((select max(id_error) from error), 0) + 1, pedido_id, current_date, '?id de pedido no valido.'); 
        
        return false;
    end if;
    
    --consulta el estado actual del pedido.
    select estado into estado_pedido from pedido p where p.id_pedido = pedido_id;
    
    -- valida si el pedido ya se encuentra en estado completado.
    if estado_pedido != 'completado' then
        -- se carga en la tabla el error
        insert into error(id_error, id_pedido, f_error, motivo)
        values (coalesce((select max(id_error) from error), 0) + 1, pedido_id, current_date, '?pedido sin cerrar o ya entregado'); 
        
        return false;
    end if;
    
    -- POST VALIDACIONES
    -- inicio de transaccion
    -- actualiza el estado del pedido como entregado.
    update pedido set estado = 'entregado' where id_pedido = pedido_id; 
    
    -- por cada fila que esté relacionada con el id_pedido que fue entregado, se guarda el id_producto y cantidad en la variable registro(record).
    for registro in select id_producto, cantidad from pedido_detalle where id_pedido = pedido_id loop
    
    -- actualiza la tabla producto restando al stock_reservado la cantidad del pedido entregado.
        update producto set stock_reservado = (stock_reservado - registro.cantidad) where id_producto = registro.id_producto;
    end loop;
    return true;
end;

$$ language plpgsql;
Generación de solicitudes de reposición

El archivo SQL se encargará de generar las solicitudes de reabastecimiento de los productos que tengan bajo stock mediante un stored procedure. Para ello, se inserta una fila en la tabla reposición por cada producto cuya suma del stock disponible y del reservado sea menor o igual al punto de reposición. La cantidad a reponer será la que permita llegar al stock máximo del producto y el estado de la solicitud se grabará como pendiente. La fecha de solicitud corresponderá a la fecha actual. El procedimiento retornará false en caso de que ya exista previamente, aunque sea una solicitud de reabastecimiento con la fecha igual a la actual, esto se basa en el razonamiento de que si existe aunque sea una solicitud con la fecha igual a la actual, el procedimiento fue ejecutado previamente en el día de la fecha. En caso contrario, retorna true.

create or replace function generar_solicitud_reposicion() returns boolean as $$

declare

    registro record;
    cantidad_reposicion int;

begin 
    
    -- valida que no exista una solicitud de reposicion ya cargada con la fecha actual
    if exists (select 1 from reposicion where estado = 'pendiente' and fecha_solicitud = current_date) then
        return false;
    end if;
    
    -- recorre cada producto verificando si está bajo de stock
    for registro in select * from producto loop
        if (registro.stock_disponible + registro.stock_reservado) <= registro.punto_reposicion then
            -- calcula la cantidad que se necesita reponer
            cantidad_reposicion = registro.stock_maximo - (registro.stock_disponible + registro.stock_reservado);
            
            -- se inserta un nuevo registro de solicitud en la tabla reposicion
            insert into reposicion values (registro.id_producto, current_date, cantidad_reposicion, null, 'pendiente');
        end if;
    end loop;
    
    return true;
    
end;

$$ language plpgsql;
Envio de emails a clientes

El archivo SQL se encargará de la generación de emails mediante un trigger, el cual se ejecuta cada vez que:

  • Cada vez que se haga efectivo el cierre de un pedido, se genera un email con el asunto 'Pedido aceptado', e indicando en el cuerpo del email los datos del pedido y el detalle de los productos solicitados.

  • Cada vez que un pedido sea cancelado, se genera un email con el asunto 'Pedido cancelado', e indicando en el cuerpo del email los datos del pedido y el detalle de productos.

  • Cada vez que un pedido sea entregado, se genera automáticamente un email con el asunto 'Pedido entregado', e indicando en el cuerpo del email los datos del pedido y el detalle de productos.

  • Y, por último, un email con el asunto 'Encuesta de satisfacción', incluyendo en el cuerpo del email un texto breve que lo invite a completar una encuesta.

create or replace function enviar_mail() returns trigger as $$

declare
    this_pedido pedido%rowtype;
    email_del_cliente text;
    nombre_del_cliente text;
    cuerpo text;
    direccion_de_entrega varchar(60);
    detalles text;
    
begin

    this_pedido := new;
    select email into email_del_cliente from cliente where id_usuarie = this_pedido.id_usuarie;
    select nombre into nombre_del_cliente from cliente where id_usuarie = this_pedido.id_usuarie;
    select d.direccion into direccion_de_entrega from direccion_entrega d where d.id_usuarie = this_pedido.id_usuarie and d.id_direccion_entrega = this_pedido.id_direccion_entrega;
    select string_agg('ID del producto: ' || id_producto || ', cantidad: ' || cantidad || ', precio unitario: ' || precio_unitario, chr(10)) into detalles from pedido_detalle where id_pedido = this_pedido.id_pedido;
    
    if this_pedido.estado = 'completado' then
        -- los valores son de prueba
        cuerpo := 'Hola ' || nombre_del_cliente || ', te enviamos este mail para confirmarte que el pedido con el ID numero: ' || this_pedido.id_pedido || ' ha sido aceptado, a continuacion te dejamos los detalles del mismo' || chr(10)
                || 'Fecha de pedido: ' || this_pedido.f_pedido || chr(10)
                || 'Fecha de entrega: ' || this_pedido.fecha_entrega || chr(10)
                || 'Recibiras tu envio entre las: ' || this_pedido.hora_entrega_desde|| chr(10)
                || 'Hasta las: ' || this_pedido.hora_entrega_hasta|| chr(10)
                || 'Costo de envio: ' || this_pedido.costo_envio|| chr(10)
                || 'Monto total: ' || this_pedido.monto_total|| chr(10)
                || 'Direccion de entrega: ' || direccion_de_entrega|| chr(10)
                || 'Detalles del pedido: ' || chr(10) || detalles || chr(10);
                
        insert into envio_email values (COALESCE((select max(id_email) + 1 from envio_email), 0), current_timestamp, email_del_cliente, 'Pedido aceptado', cuerpo, current_timestamp, 'enviado');
        
    elsif this_pedido.estado = 'cancelado' then
        cuerpo := 'Hola ' || nombre_del_cliente || ', te enviamos este mail para confirmarte que el pedido con el ID numero: ' 
                || this_pedido.id_pedido || ' ha sido cancelado, a continuacion te dejamos los detalles del mismo' || chr(10)
                || 'Fecha de pedido: ' || this_pedido.f_pedido || chr(10);
                    
        insert into envio_email values (COALESCE((select max(id_email) + 1 from envio_email), 0), current_timestamp, email_del_cliente, 'Pedido cancelado', cuerpo, current_timestamp, 'cancelado');
            
    elsif this_pedido.estado = 'entregado' then
        cuerpo := 'Hola ' || nombre_del_cliente || ', te enviamos este mail para confirmarte que el pedido con el ID numero: ' || this_pedido.id_pedido || ' ha sido enviado, a continuacion te dejamos los detalles del mismo' || chr(10)
                || 'Fecha de pedido: ' || this_pedido.f_pedido || chr(10)
                || 'Fecha de entrega: ' || this_pedido.fecha_entrega || chr(10)
                || 'Recibiras tu envio entre las: ' || this_pedido.hora_entrega_desde|| chr(10)
                || 'Hasta las: ' || this_pedido.hora_entrega_hasta|| chr(10)
                || 'Costo de envio: ' || this_pedido.costo_envio|| chr(10)
                || 'Monto total: ' || this_pedido.monto_total|| chr(10)
                || 'Direccion de entrega: ' || direccion_de_entrega|| chr(10)
                || 'Detalles del pedido: ' || chr(10) || detalles || chr(10);
                
        insert into envio_email values (COALESCE((select max(id_email) + 1 from envio_email), 0), current_timestamp, email_del_cliente, 'Pedido entregado', cuerpo, current_timestamp, 'entregado');
            -- el segundo current_timestamp deberia ser la fecha del dia siguiente.
            -- falta validar que la fecha actual current_timestamp sea igual al registro de la fecha siguiente para updatear el estado del envio a "enviado"
            
        cuerpo:= 'Te enviamos esta encuesta del pedido:' || ' ' || this_pedido.id_pedido || ' ' ||
                'para saber el nivel de satisfaccion durante el periodo de compra y envio' || chr(10);
                
        insert into envio_email values (COALESCE((select max(id_email) + 1 from envio_email), 0), current_timestamp, email_del_cliente, 'encuesta', cuerpo, null, 'pendiente');
    end if;

    return new;
end;
